# Creditcard 

Download dataset from the following link :
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Description :
Credit card fraud detection refers to the process of identifying unauthorized or fraudulent transactions in order to protect consumers and financial institutions from financial loss. With the rapid rise of online transactions and digital payments, credit card fraud has become a significant challenge, costing billions of dollars annually worldwide. Detecting fraudulent transactions in real time is a critical aspect of maintaining trust in the financial system.


## 📝 Project Description
This project focuses on detecting fraudulent transactions using machine learning.  
We have used a **Logistic Regression** model, leveraging a credit card transaction dataset. The goal is to accurately classify transactions as fraudulent or legitimate.

---

## 📈 Workflow

![Workflow](./Work%20flow%20image.jpg)

The major steps involved are:

1. **Credit Card Data**  
   Load the credit card transaction dataset.

2. **Data Preprocessing**  
   Handle missing values, encode categorical variables if needed, and standardize features.

3. **Data Analysis**  
   Understand data distribution, visualize patterns, and detect any imbalances in the dataset.

4. **Train-Test Split**  
   Split the dataset into training and testing sets to evaluate the model's performance.

5. **Logistic Regression Model**  
   Train a logistic regression model to predict fraudulent transactions.

6. **Evaluation**  
   Evaluate the model's performance using metrics like accuracy, precision, recall, and F1-score.
